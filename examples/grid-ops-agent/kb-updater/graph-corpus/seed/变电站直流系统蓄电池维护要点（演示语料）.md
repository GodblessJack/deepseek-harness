# 变电站直流系统蓄电池维护要点（演示语料）

（本篇为 14 票图谱增量演示的自编演示语料，非正式规程，内容按通用运维常识编写。）

变电站直流系统（阀控式铅酸蓄电池组）是继电保护与断路器操作电源的最后屏障，其缺陷直接影响变电站安全运行。常见缺陷形态：单体蓄电池电压异常（浮充电压偏离整组平均值过大）、蓄电池壳体鼓包变形、极柱腐蚀、连接条发热、蓄电池组容量不足（核容试验不合格）。定级口径：直流系统绝缘下降或蓄电池组容量低于额定容量的 80% 定为严重缺陷，须限期处理；单只蓄电池电压异常但整组尚能满足直流负荷定为一般缺陷；两组蓄电池全组失效或直流母线失压定为危急缺陷。

维护流程：变电运维班每月普测蓄电池组单体电压与整组电压并记录台账，检查蓄电池室通风与环境温度（宜保持在 5～30℃）；每季度检查连接条压降与极柱腐蚀情况，涂抹凡士林防腐蚀；按周期由电气试验班开展核容试验（10 小时率放电），容量不合格的整组蓄电池列入更换计划，更换作业由检修班办理第二种工作票执行，作业中用临时直流电源保住直流母线。

安全注意事项：蓄电池室禁止明火，使用防爆型照明与通风设备；核对极性与扭矩要求，防止连接条过紧损伤极柱；核容放电时先接入放电仪再开回路，放电结束先恢复充电再撤放电仪。维护记录随设备台账归档，含测量时间、环境温度、单体电压极差与作业人员。
