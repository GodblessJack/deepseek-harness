# 主变压器渗漏油处置要点（演示语料）

（本篇为 14 票图谱增量演示的自编演示语料，非正式规程，内容按通用运维常识编写。）

主变压器（油浸式电力变压器）渗漏油是变电运维中的高频缺陷，多发生在油枕、套管法兰、散热器阀门与放油塞等密封部位。渗漏油缺陷按《电力变压器运行规程》（DL/T 572-2021）口径定级：油位可见下降但暂不影响运行定为一般缺陷；渗漏速度较快、油位接近下限定为严重缺陷；大量喷油或油位低于瓦斯继电器取油口定为危急缺陷。

处置流程：变电运维班发现渗漏油后，先在缺陷台账登记缺陷部位与渗漏速度，拍照留证；通知变电检修班到现场处理。检修人员办理第二种工作票后，清洁渗漏部位表面，更换老化密封垫（耐油橡胶垫），按对角顺序均匀紧固法兰螺栓；处理完毕后由运维人员连续三天复核油位并记录。若渗漏源于散热器阀门内漏，则需申请停电更换阀门，由调度批准检修计划。

常用工具与材料：耐油橡胶密封垫、力矩扳手、油位计、吸油毯。涉及带电取样或近距离检查时，必须保持与带电部位的安全距离，并履行现场安全监护。
