# 电力电缆终端头发热监测要点（演示语料）

（本篇为 14 票图谱增量演示的自编演示语料，非正式规程，内容按通用运维常识编写。）

电力电缆终端头（电缆终端接头）发热是电缆运维的高频缺陷，常见部位为终端应力锥、接线端子（线鼻子）压接处与接地线连接点。发热多因压接不良、氧化膜接触电阻增大或负荷电流过大引起。按缺陷定级口径：相对温差超过 95% 或热点温度超过 80℃ 定为危急缺陷；热点温度 60～80℃ 定为严重缺陷；温升轻微、趋势稳定定为一般缺陷。

监测流程：电缆运维班按周期对电缆终端开展红外测温普测，重载线路与夏季高峰负荷期间加密监测；测温记录录入缺陷台账，标注测温时间、负荷电流与环境温度。发现异常发热后，先用红外热像仪复测并拍摄热像图，通知电气试验班做回路电阻测试与相间比较；确认压接不良后由电缆检修班申请停电处理，重新压接接线端子并涂覆导电膏。

红外测温作业须满足安全距离要求，禁止跨越遮拦测温；热像图作为缺陷定级依据随缺陷记录归档。电缆终端发热缺陷处置后，运维班在后续一个月内对该终端每周复测一次，确认温升恢复正常。
