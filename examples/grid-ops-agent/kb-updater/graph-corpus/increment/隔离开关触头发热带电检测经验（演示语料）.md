# 隔离开关触头发热带电检测经验（演示语料）

（本篇为 14 票图谱增量演示的投喂增量文档：入库前快照 → 投喂本文 → 图谱增量 → 入库后快照。自编演示语料，非正式规程，内容按通用运维常识编写。）

隔离开关触头发热是变电站母线侧设备的常见缺陷，多发于触指与触头接触面、导电带连接处。发热原因包括触指弹簧疲劳压力不足、接触面氧化、触头镀层磨损。定级口径：触头热点温度超过 90℃ 或相对温差超过 95% 定为危急缺陷，须立即申请转移负荷并停电处理；热点温度 70～90℃ 定为严重缺陷，限负荷运行并限期处理；温升轻微且趋势稳定定为一般缺陷，纳入跟踪观察。

带电检测经验：运维班用紫外成像仪检查触头有无电晕放电，用红外热像仪测触头与引流线连接处温度；夜间熄灯巡查有助于发现放电亮点。发现触头发热后记录隔离开关编号、相别、热点温度、负荷电流与环境温度，并对比历史测温数据判断趋势。检修处理由变电检修班申请停电进行：打磨触头接触面并涂导电膏、更换疲劳触指弹簧、调整触头插入深度；处理后一个月内每周复测。

安全注意事项：隔离开关触头检测在母线带电情况下进行，须保持安全距离并履行监护；禁止在雷雨天气开展红外与紫外检测作业。
