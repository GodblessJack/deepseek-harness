# 图谱演示语料来源

- `seed/` 3 篇与 `increment/` 1 篇均为**自编演示语料**（电网设备运维常识性内容，为图谱构建与增量演示而写），非客户资料、非正式规程文本，不可当规程引用。
- 内容涉及的规程名称（DL/T 572-2021 等）仅作行文引用，条文细节未核对原标准。
- 用途：14 票「电网运维-图谱演示库」数据集建库与图谱增量快照对比演示（票 05 A2-3 剧本素材）。
- 历史：初版 seed 含《GIS 设备 SF6 气体泄漏巡检要点（演示语料）》，该篇在 RAGFlow v0.27.0 + deepseek-v4-flash 的 GraphRAG 实体抽取下确定性产出空子图（"subgraph is empty"），已替换为《变电站直流系统蓄电池维护要点（演示语料）》；原因未深究，遗留记录见票 14。
