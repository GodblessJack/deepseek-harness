# 10kV开关柜局部放电带电检测经验

（本文为 14 票投喂演示文档：演示「投喂 → 质检 → 入库 → 图谱增量 → 知识问答按用户投喂层引用」全链。内容按通用运维常识自编，非正式规程。）

10kV金属封闭开关柜（中压开关柜）局部放电带电检测是配电站室运维的重要手段。开关柜内绝缘缺陷（绝缘件表面污秽、电缆舱搭接不良、触头盒气隙、母排对柜体距离不足）在发展为击穿前常有局部放电征兆。检测发现局放量异常时按口径定级：柜内存在明显放电声伴暂态地电压（TEV）读数超过背景值 20dB 定为严重缺陷，需安排停电检查；TEV 超背景 10～20dB 且趋势稳定定为一般缺陷，纳入跟踪；超声波检测听到明显放电声且定位明确时无论 TEV 读数多少均按严重及以上缺陷处置。

带电检测流程：运维班每季度对站室内开关柜开展 TEV 与超声波（AE）普测，记录每面柜的三相读数与背景值；读数异常的柜体用超声波定位仪精确定位放电点（常见部位：电缆舱、触头盒、母排穿柜套管）。发现局放异常后通知电气试验班复测确认，停电检查由检修班办理第一种工作票，处理手段包括清洁绝缘件、调整母排距离、更换老化触头盒；处理后一个月内加密复测一次。

安全注意事项：开关柜带电检测不得开启柜门，保持与带电部位安全距离；检测仪器外壳接地；在窄小站室内作业时两人同行并履行监护。检测数据录入配电站室缺陷台账，标注柜号、相别、TEV/AE 读数与环境温度。
