# 配电网架空线路防雷要点

（本文为 14 票投喂演示文档（半成功场景用：入库成功、图谱目标故意配错）。内容按通用运维常识自编，非正式规程。）

配电网 10kV/20kV 架空线路防雷是配电运维的专项内容。雷击跳闸的主要途径：直击雷击中导线或电杆、感应过电压沿线路侵入站内设备、雷击配电变压器高压侧绕组。防护措施按优先级：多雷区线路安装架空地线或加强绝缘（防污闪复合绝缘子）；配电变压器高压侧装设金属氧化物避雷器并可靠接地，接地电阻按规程周期检测，超过规定值时改造接地网；线路入口与电缆终端处装设避雷器保护站内设备。

运维要点：雷雨季节前完成避雷器检测与接地电阻测量；雷击跳闸重合成功后仍应巡线确认绝缘子有无闪络痕迹；多次雷击闪络的绝缘子串列入更换计划。巡线发现绝缘子闪络、避雷器计数器动作异常时按缺陷登记，闪络痕迹明显的绝缘子定为严重缺陷，安排带电或停电更换。
