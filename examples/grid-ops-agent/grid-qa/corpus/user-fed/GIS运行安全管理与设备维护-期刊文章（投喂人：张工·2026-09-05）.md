# GIS运行安全管理与设备维护

黄博
(清远供电局,广东 清远 511500)

GIS(Gas-insulated Metal-enclosed Switchgear)是SF6全封闭式组合电器的简称,它是将变电站中除了变压器之外的所有一次设备,通过优化设计使其成为一个具有积木式组合特征的有机整体。其应用的范围十分广泛,现有的GIS产品已经可以覆盖66~750kV各电压等级的所有应用。GIS组合电器采用了SF6气体绝缘,其断路器的灭弧介质也进行了全封闭,因而具有体积小、噪音低、防污染和组合使用方便等特点,设备的安全性能、运行稳定性等都是其他敞开式电器无法相比的。同时,由于GIS组合电器的结构复杂、制造工艺精细、质量要求高,在其安装调试和运行中会存在一些问题,而且在这些问题的检测和试验上尚缺乏较为完善的手段。为保证GIS设备的安装质量,消除运行中的问题,本文从GIS组合电器的总体结构入手,在结合多年GIS设备安装调试运行维护经验和教训的基础上,通过总结与分析,提出了GIS运行安全管理与设备维护的一些策略与措施。

## 1 GIS运行安全管理与设备维护对策

### 1.1 巡检与维护

#### 1.1.1 日常巡检

GIS运行的日常巡检项目主要有:结合运行维护经验听设备运行的声音,听是否存在异常声音来判断设备运行状况;闻室内是否有异常气味,如有异常气味要立即采取防护措施并及时进行处理;SF6气室内工作压力是断路器动作时有效灭弧的重要保证,因此日常巡检中要检查压力是否正常,发现低于正常压力时要及时补充;每天对各气室内的气体压力和环境温度进行检测并做好记录;每周对断路器分合闸的次数要进行汇总和记录;配电室内要始终保持良好的通风;对隔离开关、接地开关的分合闸次数要定期进行检查;应定期检查并确保汇控柜柜门密封良好,各开关、继电器等元器件接触良好。

#### 1.1.2 定期维护

定期维护的项目主要有:要定期对SF6气体中水分的含量进行检测,并确保其符合要求;要定期检测主回路电阻并使其符合设备要求;要定期检测断路器密封面和充气接头的密封情况;要定期检测本体的传动密封部分,确保无泄漏;要定期检测密度继电器的示值,如有下降应补充SF6气体至额定值;定期检查电气二次线是否牢靠,各控制、保护回路工作是否正常;在额定气室压力和额定操作电压下检测电动操作是否正常;检测各运动机构的运行时间、同期性。

### 1.2 SF6检漏和湿度测量

#### 1.2.1 检漏

检漏主要有两种方式:一是定性测量。即利用高灵敏度探头的检漏仪器来探测设备上容易泄漏的点,当超出阀值时声光报警,这种方式有定位方便、实用的特点。一般分为简易法和局部蓄积法两种,简易定性检漏法是利用检漏仪对各密封面、管道连接等部位实时检测,从而发现泄漏点;局部蓄积法是用薄膜将测量部位包裹后,在一定时间之后再用检漏仪测量薄膜包裹内是否有SF6气体,目前后者较为常用。二是定量测量。即采用挂瓶或局部包扎的方式,在充气达24h后,用LDD2000型检漏仪进行定量检测,这种方式较为安全。定量测量的判断标准为年漏气率≤1%。

#### 1.2.2 湿度的测量

湿度测量一般在气室温度稳定之后开展,使用的仪器主要有露点微水测试仪或DP19-SH-Ⅲ型SF6微水测量仪。

为了确保测量值的准确性和可参考性,应尽可能用同一台仪器进行测量,且在测量时确保气路接头干燥,以避免气路接头部位带有的水分影响测量准确度。

### 1.3 维修时的注意事项

在GIS全封闭式组合电器中SF6气体是主要的绝缘和灭弧介质,由于设备本身制造工艺和密封器件老化等因素的影响,在其运行中难免会出现SF6气体泄漏和水分渗入现象,而这会给GIS的安全运行带来严重的威胁,因而是GIS安全管理和维护中应该高度关注的问题。对其维修时应该注意以下几个问题:一是在补充气体时,应该确保充入SF6气体的质量达标,新充入的SF6气体的纯度不应低于99.8%,充入后的纯度不应低于97%,另外四氯化碳、水分含量、纯度、酸度等技术指标都应符合国标要求。在充气前要确保所有管路干燥、干净,并注意缓充防止损坏压力表。二是GIS设备复装时应确保密封槽面干净无油污、无划痕;旧的密封圈(垫)应更换;涂密封脂时不得使其流入密封圈(垫)内侧而与SF6气体接触。三是检修人员进入气室开展检修工作之前,要对气室进行充分换气,确保气室内的含氧量达到18%以上时方可进入开展各项检修工作。

### 1.4 加强人员培训管理

由于GIS设备具有小型化、复合化、智能化等特点,其科技含量较高,在对其日常维护、安全运行管理和设备维护中要求相关人员充分掌握SF6组合电器的基础理论知识,掌握相关的技术规程、工艺标准和操作规程。因此在日常管理中,要加大对生产、运行、检修部门人员的技术、技能培训,有条件时可以组织业务技术人员赴厂家进行现场学习实践,并令其全程跟踪学习设备安装和调试过程,使运行管理人员既懂原理又懂技术、既了解设备结构又能使设备图纸和原理实践化,从而使SF6组合电器发挥更好的作用。

## 2 结束语

SF6气体是到目前为止最理想的绝缘和灭弧气体介质,其在GIS全封闭式组合电器中作为绝缘介质的实践应用,使得GIS组合电器在与敞开式电器的竞争中,凸显出其优异的性能,未来的应用前景也十分广阔。但与此同时,GIS组合电器也存在着一些自身的问题,当然这些问题不足以阻碍GIS的发展和应用。目前对GIS的安全运行管理和设备维护尚处于探索阶段,本文所述内容为笔者在工作实践中的一些经验总结,更多的经验和教训仍需要运维人员在GIS的运行维护工作实践中继续进行总结与完善。
